# ButterUI: The Companion to Any p5.js Interaction
ButterUI is a single-file JS library for use in [p5.js](https://p5js.org) to allow for responsive and easy-to-use desktop and mobile GUIs. 

## NOTICE ON CURRENT STATUS
This project __will not__ be receiving updates for a while as I continue to rethink some of the core foundations and features. 
As for a release state, I'm hoping to get one out by December, so if you are interested keep on a lookout for that. 

## How does it work?
ButterUI uses p5.js to utilize it's easy DOM integration for faster development. The core of the UI is based off of panels, usually being a pane or area of the screen with a title, actions,
and content. The main features that make it good for [p5.js](https://p5js.org) is it's Registry feature, where you can write and read values from a registry table which can be configured to
persist through saves (using browser cookies) or not. Furthermore, most all of the features I've talked about are Factory Based, so it's really easy to get started with them.
